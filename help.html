법정글 복사 즐겨찾기 설치

← 법정리스트로 돌아가기

인트라넷 법정게시판에서 한 주치 글을 한 번에 복사하는 버튼입니다. 처음 한 번만 설치하면 됩니다.

크롬(Chrome)

  1. 즐겨찾기 막대가 안 보이면 ⌘ + Shift + B(윈도우는 Ctrl + Shift + B)로 켭니다.
  2. 아래 파란 점선 버튼을 마우스로 끌어서 즐겨찾기 막대에 놓습니다.
법정글 복사

사파리(Safari)

  1. 아무 페이지에서 메뉴 책갈피 → 책갈피 추가로 즐겨찾기를 하나 만들고 이름을 법정글 복사로 정합니다.
  2. 메뉴 책갈피 → 책갈피 편집에서 방금 만든 항목을 오른쪽 클릭 → 주소 편집.
  3. 아래 [주소 복사]를 눌러 복사한 내용을 붙여넣고 Enter.

아이패드 사파리

  1. 아무 페이지에서 공유 버튼 → 책갈피 추가로 즐겨찾기를 만들고 이름을 법정글 복사로 정합니다.
  2. 책갈피 목록에서 편집 → 방금 만든 항목을 눌러 주소 칸을 지우고, 위 [주소 복사]로 복사한 내용을 붙여넣습니다.
  3. 인트라넷 법정게시판에서 주소창을 누르고 법정글 복사를 입력해 목록에 뜬 책갈피를 누르면 실행됩니다.

쓰는 법

  1. 인트라넷에 로그인하고 법정게시판을 엽니다.
  2. 즐겨찾기의 법정글 복사를 누르고, 기준 일요일을 확인한 뒤 [확인]을 누릅니다.
  3. 화면 위에 뜬 상자에서 [복사하기]를 누릅니다.
  4. 법정리스트 사이트에서 법무부장 → 붙여넣기 칸을 누르고 붙여넣기(⌘V / Ctrl+V) 한 뒤 [정리]를 누릅니다.
