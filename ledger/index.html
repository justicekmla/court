매주 이렇게 사용하세요
  1. 구글 좌석리스트에서 파일 → 다운로드 → Microsoft Excel(.xlsx)을 선택하세요. 색상 보존을 위해 CSV는 사용하지 마세요.
  2. 지난 회차 누계 파일과 이번 최종 좌석리스트를 각각 올리세요.
  3. 회차와 판결 탭, 실제 선고점수 기준을 선택하세요.
  4. 누계 생성 · 부원에게 공유를 누르세요. 각 부원은 역할 화면에서 공유 누계를 확인하고 완료를 누릅니다.
  5. 두 부원의 완료 후 최종 파일을 내려받아 Excel에서 재계산하고 저장하세요. 다음 주에는 이 파일을 올립니다.
프로베이션(P)은 올해 첫 기소·단일 항목·자격 표시를 확인해 p(점수)로 유예합니다. 기존 3회 미기소 상점의 누락 수식은 선택 회차까지 자동으로 이어 채웁니다. 2·3학년의 P 여부 p를 자격 근거로 사용하며, 유예 법정 포함 3회 내 재기소 시 이전 벌점을 복원합니다. 이미 값이 있는 회차의 수정·덮어쓰기는 지원하지 않습니다.
프로그램은 이 GitHub 사이트에서 실행됩니다. 파일 읽기와 계산은 브라우저에서 처리하며, 공유 버튼을 누르면 결과 파일과 확인 상태를 기존 Firebase에 저장합니다.
